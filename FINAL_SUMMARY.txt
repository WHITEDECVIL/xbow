## 💻 COMMAND EXAMPLES

### Network Scanning
```bash
xbow scan --target 192.168.1.0/24 --scan-type network
xbow scan --target 192.168.1.100 --ports 80,443,22 --threads 4
```

### Web Scanning
```bash
xbow scan --target https://example.com --scan-type web
xbow scan --target https://example.com --scan-type web --depth 3 --generate-report
```

### DNS Enumeration
