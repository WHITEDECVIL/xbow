# XBOW Project Structure Documentation

## Directory Structure Overview

This document outlines the complete structure for XBOW's configuration, logging, metrics, models, and todo management directories.

### .qodo/ (Code Todo Management)
Contains agent definitions and workflow configurations for code review and documentation tasks.

### config/ (Configuration Files)
Centralized configuration for all XBOW components, including scan profiles and vulnerability databases.

### logs/ (Log Storage)
Runtime logs from scan execution, including audit trails and error logs.

### metrics/ (Metrics & Analytics)
Aggregate metrics, performance data, and statistical analysis of scans.

### models/ (Machine Learning Models)
Pre-trained ML models for vulnerability classification and severity prediction.
