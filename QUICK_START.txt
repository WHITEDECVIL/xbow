🔍 EXAMPLE: WEB VULNERABILITY SCAN WITH REPORT
═══════════════════════════════════════════════════════════════════════════

Run this:

  xbow scan --target https://example.com \
    --scan-type web \
    --depth 2 \
    --threads 4 \
    --generate-report

This will:
  ✓ Analyze security headers
  ✓ Test for injection vulnerabilities
  ✓ Crawl the website
  ✓ Check SSL/TLS configuration
  ✓ Generate HTML report
  ✓ Export JSON data

Results saved to: results/ directory

⚙️ CUSTOMIZE BEHAVIOR
═══════════════════════════════════════════════════════════════════════════

Edit config/xbow.json to change:
  - Scan timeout (default: 30s)
  - Thread count (default: 4)
  - Port ranges
  - Log level
  - Output directory

Use scan profiles:
  xbow scan --target example.com --profile quick       # Fast
  xbow scan --target example.com --profile standard    # Balanced
  xbow scan --target example.com --profile aggressive  # Comprehensive

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

"nmap not found":
  sudo apt-get install nmap        # Linux
  brew install nmap                # macOS

"Connection refused":
  - Check target is online: ping example.com
  - Try HTTP: xbow scan --target http://example.com

Slow scanning:
  - Use quick profile: --profile quick
  - Reduce port range: --ports 1-100
