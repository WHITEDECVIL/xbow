# XBOW Configuration Files

This directory contains all configuration files for XBOW operations.

## Files

- **xbow.json** - Main configuration (timeouts, logging, AI settings)
- **profiles.json** - Predefined scan profiles
- **cve_database.json** - CVE and vulnerability database
- **defaults.json** - Default values for all components
- **logging.json** - Logging configuration
- **ai_models.json** - AI/ML model configurations
