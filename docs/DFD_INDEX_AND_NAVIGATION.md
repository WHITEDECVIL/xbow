## 🎯 Key Concepts

### Level 0 (Context Diagram)
- Shows XBOW as **single black box**
- Shows **4 external connections:**
  1. **User** → Commands in, Reports out
  2. **Target Systems** → Responses in, Probes out
  3. **Configuration** → Database in, Cache out
  4. **Reports** → Output destination

### Level 1 (System-Level)
- Decomposes XBOW into **9 major processes**
- Shows **5 data stores**
- Shows **16 distinct data flows**
- Represents **functional architecture**

### Key Processes
- **P1:** CLI (user interface)
- **P2:** Orchestrator (coordination)
- **P3-P5:** Scanners (network, web, DNS) - **PARALLEL**
- **P6:** Aggregator (data consolidation)
- **P7:** Vulnerability Detector (CVE matching)
- **P8:** AI/ML Engine (prediction & classification)
- **P9:** Report Generator (output formatting)

### Key Data Stores
- **D1:** Vulnerability Database (CVEs)
- **D2:** Scan Profiles (configurations)
- **D3:** Model Registry (ML models)
- **D4:** Reports (output)
- **D5:** Audit Logs (operational)
